## Verification

All Minke contracts are fully verified on Etherscan and equivalent block explorers. Once deployed, you can verify any contract by:

1. Looking up the address on Etherscan
2. Clicking "Contract" → "Read Contract" to inspect immutable parameters
3. Confirming `VestingFactory` address matches this page

## Security

Minke contracts are audited by independent security firms. Audit reports will be published to the Minke GitHub repository before mainnet launch.

Active bug bounty program details will be published alongside the mainnet launch announcement.

## ABI Downloads

Contract ABIs will be available at:

- GitHub: `github.com/minke-finance/contracts`
- npm: `@minke-finance/contracts`

The npm package will export TypeScript types, contract addresses, and ABIs for all supported networks.

```typescript
import { VestingFactory, ContractRegistry } from "@minke-finance/contracts";
import { mainnet } from "@minke-finance/contracts/addresses";

const factory = new ethers.Contract(
  mainnet.VestingFactory,
  VestingFactory.abi,
  signer
);
```
