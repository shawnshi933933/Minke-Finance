# Vesting Token (VT)

A Vesting Token (VT) is a fungible ERC-20 that represents a 1:1 claim on the underlying token at vesting maturity. VTs are minted when a depositor wraps a vesting position via `VestingFactory`.

## Minting

```solidity
function createTranche(
  address underlying,
  uint256 amount,
  uint64 vestStart,
  uint64 vestEnd
) external returns (address vestingToken);
```

The depositor transfers `amount` of the underlying token into the new `VestingToken` contract. The contract mints exactly `amount` VTs (1:1) and returns them to the depositor.

```
Deposited:  1,000,000 TOKEN
VTs minted: 1,000,000 VT  (1:1, no upfront fee)
```

## Phase 1: Pro-Rata Staking

### Staking

```solidity
function stakeVT(uint256 amount) external;
```

Deposits `amount` of VT into the staking pool. The contract records the holder's `userDebt` at the current `accVTPerShare` value.

### Checkpointing

```solidity
function checkpointVesting() external;
```

Reads the current vested amount from the schedule and updates the global `accVTPerShare` accumulator. Anyone can call this at any time — it is permissionless and idempotent.

### Claiming

```solidity
function claimT() external;
```

Transfers the caller's pending staking rewards. The calculation runs in two steps:

```
// Step 1: compute how much has accrued since last claim
pending = (stakedVT × accVTPerShare) - userDebt

// Step 2: reset the debt baseline so future claims start from now
userDebt ← stakedVT × accVTPerShare
```

`userDebt` tracks the accumulator value already accounted for. At any point before claiming, `userDebt` is lower than `stakedVT × accVTPerShare` because the accumulator has grown since the last interaction — that difference is the unclaimed amount. After the claim, the debt is brought up to the current accumulator value, so the next claim starts fresh.

<Callout type="info">
Stakers who claim early "exit" the vesting position with partial value. Their remaining staked VT continues to accumulate unlocks until they claim again or unstake.
</Callout>

### Unstaking

```solidity
function unstakeVT(uint256 amount) external;
```

Removes `amount` from the staking pool. Pending rewards remain claimable via `claimT()`.

## BuybackPool Early Exit

During Phase 1, VT holders can exit early via the BuybackPool rather than waiting:

```solidity
function convertViaBuyback(uint256 vtAmount) external;
```

The BuybackPool sources T from the vault as tokens vest according to the schedule. A protocol fee (e.g. 5%) is charged on the conversion:

```
convertViaBuyback(100 VT)
  → caller receives: e.g. 95 T
  → protocol fee:    e.g.  5 T → treasury
```

## Phase 2: 1:1 Redemption

After `endVesting()` is called (once the vesting schedule end time is reached), Phase 2 opens.

```solidity
function endVesting() external;
```

This finalises the accumulator, computes `excessT` (all unclaimed underlying), and enables `redeemVT()`.

### Redemption

```solidity
function redeemVT(uint256 vtAmount) external;
```

Burns `vtAmount` of VT and transfers the proportional share of `excessT` to the caller:

```
redeemed = vtAmount × (excessT / totalSupplyVT)
```

Because each Phase 1 claim reduces both `excessT` and the outstanding VT supply by the same amount, this ratio is always exactly **1:1**:

```
redeemed = 1 underlying per VT
```

<Callout type="tip">
Phase 2 redemption is always exactly 1:1, regardless of how much was claimed during Phase 1. No protocol fee applies to Phase 2 redemption.
</Callout>

## VT Token Properties

| Property | Value |
|---|---|
| Standard | ERC-20 |
| Minting | 1:1 with underlying at tranche creation |
| Burning | On BuybackPool conversion or Phase 2 redemption |
| Transferability | Fully transferable — no restrictions |
| Decimals | Matches the underlying token |

## Lifecycle Summary

```
Deposit underlying → Mint VT (1:1)
         ↓
     Phase 1
  ┌─────────────────────────────────────────┐
  │  Stake VT → earn pro-rata unlocks (no fee) │
  │  OR                                        │
  │  BuybackPool → early T exit (e.g. 5% fee)  │
  └─────────────────────────────────────────┘
         ↓
     Phase 2
  redeemVT() → 1:1 T (no fee)
```
